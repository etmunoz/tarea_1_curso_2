# 02 · Crear el repo de contenido `tarea_1_curso_2`

**Fecha:** 2026-11-10
**Objetivo:** dejar el material del taller limpio y versionado en un repo propio,
separado de la herramienta (`descargaweb`), para poder referenciarlo desde otra
sesión o máquina.

## Prompt

> Separa el contenido de la herramienta: crea la carpeta `tarea_1_curso_2` y, dentro,
> el taller extraído a Markdown con un `README.md` índice. Inicializa git y crea un
> repositorio **privado** en GitHub (cuenta `etmunoz`) con ese contenido.

## Verificación pedida

- Repo privado `etmunoz/tarea_1_curso_2` con el material subido.
- `README.md` con la tabla de las 10 páginas.
