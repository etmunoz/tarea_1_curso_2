# 21 · Windows: clonar el repo y leer las instrucciones (sin ejecutar)

**Fecha:** 2026-11-10 · **Equipo:** Windows (nodo Tomás) · **Asistente:** Claude Code (app de escritorio)

## Prompt

> tienes que acceder a mi repo tarea_1_curso_2 de etmunoz y clonarla usando la carpeta que
> ya cree: "C:\Users\etmun\proyecto\tarea_1_curso_2". En la repo vas a ver las instrucciones
> para Windows, las lees y paras, y revisamos lo que vayas a realizar, antes de que lo
> realices, para darte el vamos.

## Verificación pedida

- Repo clonado en la carpeta indicada (no en `%USERPROFILE%\proyectos` como dice la guía).
- Leer la sección Windows de la guía y los `scripts/*.ps1`, **sin ejecutar nada**.
- Presentar el plan y esperar la aprobación.
