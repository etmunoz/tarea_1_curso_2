# 23 · Windows: cambiar el puerto de Redis (6379 ocupado)

**Fecha:** 2026-11-10 · **Equipo:** Windows (nodo Tomás)

## Prompt

> cambia el puerto para este caso de windows

## Verificación pedida

- Levantar el Redis del proyecto (`reiki-redis`) sin chocar con otro Redis ya existente en el PC.
- No afectar el Mac: los valores por defecto siguen siendo 6379 / 8001.
- Cargar el RAG de Reiki y comprobar una búsqueda.
